README – PYTHON PROJECTS

Project Overview
----------------
This collection contains 10 beginner-level Python programs. Each program demonstrates basic programming concepts such as input/output, calculations, conditional statements, loops, lists, and validation.

Included Programs
-----------------
1. Electricity Billing
   Calculates an electricity bill from the number of units entered, applies the relevant rate slab, and adds a fixed charge.

2. Employee Payroll
   Accepts an employee's name, basic salary, allowance, and overtime pay. Calculates gross salary, deduction, and net salary.

3. Retail Billing
   Accepts product details and quantities, calculates item amounts, applies a discount based on the total, and displays the final bill.

4. Campus Event Financial Planning
   Calculates total event expenses, income from registration fees and sponsorship, and the resulting balance. Reports whether the event is profitable or has a loss.

5. Examination Result
   Accepts marks for five subjects, calculates total marks and percentage, and displays the result and grade.

6. ATM Transaction Simulation
   Provides a menu for deposits, withdrawals, balance checking, and exiting. Includes checks for invalid amounts, insufficient balance, and withdrawal limits.

7. Student Performance Analysis
   Accepts a student's name and three exam marks, calculates the average, compares the first and third marks, and displays a performance category.

8. Fuel Consumption and Route Comparison
   Calculates estimated fuel required and travel cost for a car, bike, and bus using the mileage values defined in the program, then identifies the lowest-cost option.

9. Password Validation
   Checks whether a password has at least eight characters and includes uppercase and lowercase letters, a digit, and one of the supported special characters (!@#$%^&*).

10. Food Waste Monitoring
    Collects meals prepared and served for each day of the week, calculates leftovers and waste percentage, flags high waste, and prints a weekly summary.

Requirements
------------
- Python 3 installed on your computer.
- A text editor or Python IDE, such as Visual Studio Code.
- A terminal or command prompt to run the programs.

How to Run
----------
1. Save or copy the project files into a folder.
2. Open that folder in Visual Studio Code or a terminal.
3. Open a terminal in the folder.
4. Run one program at a time using the matching filename. For example:

   python "project-1(1).py"

   Replace the filename with the program you want to run. If your files have been renamed, use their current filenames.
5. Follow the prompts and enter the requested values.
6. For the ATM Transaction Simulation, choose menu options until you select Exit.
7. For Food Waste Monitoring, enter meals prepared and served for all seven days.
